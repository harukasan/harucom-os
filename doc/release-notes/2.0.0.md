# Harucom OS 2.0.0

Harucom OS 2.0 plays the music, runs the lights, and now fits in a browser tab.

- Browser build: open [try.harucom.org](https://try.harucom.org/). Emscripten
  compiles the firmware to WebAssembly, so it runs in the browser.
- Audio: DMA output with sample-accurate scheduling, QOA and WAV sample files
  streamed from flash, and Synth, which makes sounds in Ruby.
- Lighting: DMX512 from a background engine, driven by Johakyu live coding
  patterns.
- Japanese input: T-Code and SKK fixes.
- Display and shell: a 2x text console, large files that scroll smoothly, and
  more editing keys in IRB and picorabbit.
